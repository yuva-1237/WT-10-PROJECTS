# Project 09: College Event Registration System - Screenshots

This directory contains visual captures of the application in operation:

1. `01_event_catalog.png`: Dynamic event catalog with categories (Technical, Cultural, Sports, Workshop, Seminar), search bar, and deadline/seat badges.
2. `02_registration_modal.png`: Student registration modal with student details, validation feedback, and event synopsis.
3. `03_registration_pass.png`: Generated event pass featuring unique Registration ID (`REG-EVT-XXXX`) and simulated QR verification code.
4. `04_my_registrations.png`: Student view of booked registrations with cancellation options.
5. `05_admin_event_manager.png`: Admin panel for creating/editing events, managing capacity, viewing registered participants, and exporting CSV rosters.
