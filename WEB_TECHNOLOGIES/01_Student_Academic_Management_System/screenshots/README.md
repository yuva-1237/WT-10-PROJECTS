# Screenshots & UI Layout Guide - Student Academic Management System

This directory documents the key views of the application:

1. **Admin Dashboard**:
   - Dynamic KPI metric cards (Total Students, Enrolled Departments, Overall Pass Percentage, Average CGPA).
   - Interactive Students Table with real-time search, department filter, and action buttons (Edit, Delete, Manage Marks).
   - "Add Student" Modal with comprehensive client-side regex validation.

2. **Academic Marks Entry & Attendance Modal**:
   - Tabular layout for all registered curriculum subjects.
   - Dynamic real-time calculation of Total Mark (Internal + External) and Letter Grade (O to U).
   - Subject attendance percentage input with color-coded warning (<75% eligibility warning).

3. **Student Portal View**:
   - Student ID lookup / login simulator.
   - Comprehensive Semester Grade Sheet with subject codes, credits, marks, attendance, and dynamic CGPA calculation badge.
   - Print Grade Sheet functionality.
