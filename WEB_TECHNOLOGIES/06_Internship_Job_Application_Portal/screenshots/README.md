# Screenshots & UI Layout Guide - Internship & Job Application Portal

This directory documents the campus recruitment and placement portal interface:

1. **Student Job Board & Filterable Directory**:
   - Filter bar with search by job title, company, or skills tag, plus Job Type (Full-Time, Internship, Remote) and Location filters.
   - Job vacancy card grid with company branding, eligibility criteria, required skills chips, deadline badge, and "Apply Now" button.
   - Application modal with candidate profile fields and client-side resume file validator (`.pdf` / `.docx`).

2. **Student My Applications Tracker**:
   - Tabular and card view of submitted applications.
   - Multi-step visual application tracker indicating progression through: `Applied` → `Under Review` → `Shortlisted` → `Interview` → `Selected` / `Rejected`.

3. **Recruiter & Placement Cell Dashboard**:
   - Recruitment metrics: Active Job Openings, Total Applications Received, Candidates Shortlisted, and Selected Hires.
   - Candidate management roster with action buttons: `Shortlist`, `Interview`, `Select`, `Reject`.
   - Post New Job opening modal.
