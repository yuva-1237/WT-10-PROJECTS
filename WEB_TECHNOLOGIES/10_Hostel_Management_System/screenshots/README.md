# Project 10: Hostel Management System - Screenshots

This directory contains visual captures of the application in operation:

1. `01_warden_dashboard.png`: Warden overview dashboard displaying live metrics (Total Rooms, Occupied Rooms, Available Rooms, Pending Leave Requests, Pending Complaints) and quick action panels.
2. `02_room_occupancy_matrix.png`: Interactive room grid classified by Block and Floor showing real-time occupancy counts, capacities, and visual vacancy meters.
3. `03_room_allocation_modal.png`: Allocation and transfer modal for student bed assignments, showing room availability and previous room clearance.
4. `04_student_resident_portal.png`: Resident view displaying room details, assigned roommates, fee status badge, and history of submitted leave/maintenance requests.
5. `05_leave_approval_workflow.png`: Warden review queue with parental consent indicators, date ranges, and one-click Approve/Reject actions with remarks.
