# Screenshots & UI Layout Guide - College Complaint & Maintenance Portal

This directory documents the campus facility maintenance interface:

1. **Student Complaint Lodging & History View**:
   - New Complaint form featuring 9 categorized disciplines (`Classroom`, `Laboratory`, `Wi-Fi`, `Electricity`, `Water`, `Hostel`, `Cleanliness`, `Infrastructure`, `Other`).
   - Campus Location, Priority selector (Low, Medium, High), Description textarea, and optional image upload with preview thumbnail.
   - Complaint Tracking Table displaying ticket ID, Category, Location, Assigned Technician, and visual progress pill badge.
   - Feedback submission modal for tickets marked `Resolved` (5-star rating selector and feedback comment box).

2. **Sequential Maintenance Workflow Timeline**:
   - Ticket details view displaying strict 5-stage workflow:
     `Submitted` → `Assigned` → `In Progress` → `Resolved` → `Closed`.

3. **Estate Office / Facility Admin Dashboard**:
   - Live KPI metric cards: `Total Complaints`, `Pending`, `In Progress`, `Resolved`.
   - Comprehensive complaints management table with technician assigner and status updater buttons.
