# Screenshots & UI Layout Guide - Online Examination System

Key screens and views documented in this application:

1. **Student Registration & Instructions Screen**:
   - Examination instructions, duration disclosure, and candidate registration form (Student ID, Name, Department).
   - "Start Online Exam" trigger button.

2. **Interactive Live Examination Environment**:
   - Sticky Header with countdown timer and pulse warning when under 2 minutes.
   - Main Question Card with single-choice interactive radio options and question counter.
   - Question Palette Grid (numbered buttons color-coded: Unattempted / Grey, Answered / Green, Flagged for Review / Yellow).
   - Bottom Action Bar: Previous, Next, Clear Response, Flag for Review, and Final Submit buttons.

3. **Instant Automated Result & Performance Breakdown**:
   - Performance KPI Banner: Score Percentage, Pass/Fail status, Time Taken.
   - Question-by-Question Detailed Review highlighting Candidate Choice vs. Correct Answer and comprehensive explanation.

4. **Admin Question Bank & Configuration Panel**:
   - Add/Edit Question Modal with 4-choice inputs, correct answer selector, and explanation box.
   - Exam Duration configuration controller.
